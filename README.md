# PIXZZEN website (dark green theme)

Static site: index, about, team, services, projects, contact.

- Theme colours: `css/style.css` (`:root` variables at the top).
- Put your existing images in `assets/images/` using these names:
  about-office.png, story-main.webp, card-development.webp, card-graphic.webp, card-video.webp, card-marketing.webp,
  development-services.png, design-services.png, editing-services.png, marketing-services.png
  (missing images simply show a green gradient).
- Replace placeholder content: phone/WhatsApp/email/address (footer + contact page), sample reviews (home), and sample projects (projects.html).
- The contact form submits through Web3Forms. Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `contact.html` with the Web3Forms access key before accepting submissions.
